# 📘 Numerical Methods Practice

Welcome to my **Numerical Methods Practice** repository.

This repository contains my learning, practice, and Python implementations of different **Numerical Methods** used to solve mathematical problems approximately using computational techniques.

The main purpose of this repository is to understand the **concepts, mathematical formulas, algorithms, and Python implementations** of Numerical Methods through practical coding.

---

## 🎯 Objectives

- Understand the fundamental concepts of Numerical Methods
- Implement numerical algorithms using Python
- Practice solving mathematical problems computationally
- Understand iteration-based methods
- Compare different numerical techniques
- Improve problem-solving and programming skills

---

## 🐍 Programming Language

**Python 3**

---

## 📚 Methods Covered

### 🔹 Root Finding Methods

Methods used to find approximate roots of nonlinear equations.

- Bisection Method
- False Position Method
- Newton-Raphson Method
- Secant Method
- Fixed Point Iteration

### 🔹 Linear Algebraic Equations

Methods used to solve systems of linear equations.

- Gauss Elimination
- Gauss-Jordan Elimination
- LU Decomposition

### 🔹 Interpolation

Methods used to estimate unknown values from known data points.

- Newton Forward Interpolation
- Newton Backward Interpolation
- Lagrange Interpolation

### 🔹 Numerical Differentiation

Methods for approximating derivatives numerically.

- Forward Difference
- Backward Difference
- Central Difference

### 🔹 Numerical Integration

Methods for approximating definite integrals.

- Trapezoidal Rule
- Simpson's 1/3 Rule
- Simpson's 3/8 Rule
